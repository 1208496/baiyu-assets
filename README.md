# 红瞳的莉莉亚娜 · 图源

《红瞳的莉莉亚娜》角色卡的图片仓库。卡里只有拼址规则，图全在这里；**新图丢进对应路径就生效**，不用重新打包。

## 目录

```
assets/
├─ char/liliana/{m|s}/{maid|shirt|knit|nude}.webp   定版立绘（m=顺从态 / s=强势态）
├─ char/liliana/{m|s}/maid/skirt.webp               撩裙差分
├─ h/{m|s}/{体位}_{1|2}.webp                        H CG（1=插入 / 2=射精后）
└─ bg/{door|room|bedroom|kitchen|porch}.webp        背景，兜底 bg/default.webp
```

## 规格

- 全部 **1248×1824**、透明 WebP；文件名全 ASCII
- 外观已冻结：白发马尾 + 黑发绳 + 白睫毛 + 红瞳 + 巨乳宽臀（见项目内 `tools/appearance_lock.json`）
